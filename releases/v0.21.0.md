# Housekeeping 0.21.0

Progress you can actually see, and a way back out of the disk browser as well as in.

## Bars instead of spinners

A spinner answers "is it working". It does not answer "how much longer", and on this
Mac the two operations that take longest were both answering with a spinner.

- **Update Apps** now shows a bar across the whole run: *3 of 5 updated*, with the name
  of the one being worked on underneath. Rows are the unit because a row is the only unit
  with a real length — a Homebrew cask is one command, a GitHub release is a download of
  an unknown size, and the App Store is whatever the App Store decides. Saying "3 of 5"
  is true for all three; a byte-percentage would be invented for two of them.
- **The reading pass** behind that screen has a bar too, in two honest states. While the
  bundles are being counted there is no denominator yet, so the bar travels instead of
  filling — and says *Counting what is installed*. The moment the inventory lands the
  real length is known: *Reading 34 of 210*, filling as each application and package is
  asked once.
- **Housekeeping's own update** is six named steps, so its bar is the step count:
  *Step 3 of 6*, with the step's own sentence underneath, above the list that says what
  each step is doing.

## The disk browser goes back and forth

**Forward** now sits beside Back (⌘]), and so does the shortcut. Back remembers the way
you came in; Forward remembers the folder you left to come back out, and opening anything
new clears it, because from there there is no single way forward. The path bar above the
list was already clickable — every step of it — and still is.

Measuring the disk, which used to show a spinner and two live counters, now shows its
length: **5 of 134 top-level folders**, filling as the walk finishes each one, with the
file count, the bytes read and the folder being read right under it. The tree has no
total, so the top level is the only honest fraction — and it is the level that takes the
time.

## Still smooth

The previous version stopped the octopus animating for an empty room; this one keeps her
at twenty frames a second whenever she can be seen, which is smoother than the twelve the
menu bar used to run. Measured with the window open and frontmost: about 2.5% of one core.
Idle in the menu bar, nothing open: 0.0%.

## Downloads

- **Housekeeping-macOS-universal.zip:** Apple silicon and Intel in one app.
- **Housekeeping-macOS-arm64.zip:** Apple-silicon Macs only.
- **Housekeeping-macOS-x86_64.zip:** Intel Macs only.
- **SHA256SUMS.txt:** checksums for all three ZIPs.

Requires macOS 13 or later. The Bookbind screen needs Python 3 with `mutagen`
(`python3 -m pip install mutagen`) and `ffmpeg` on the Mac.

The app is ad-hoc signed. Developer ID signing and notarization have not been completed.
