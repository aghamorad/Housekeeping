# Housekeeping 0.19.0

Bookbind's screen can now be handed a folder by dragging it in from the Finder, and a run has a panel that follows it to the end.

## Drop a folder on Bookbind

Open **Bookbind** from the sidebar and drag a folder of audio onto the window. The folder becomes the book's folder — the one the finished `.m4b` is written into, and the one the originals are moved aside inside — and its audio files land in the chapter list in order. Loose audio files dropped the same way are added to the list already there, with the folder worked out from where they live.

A dotted veil comes up while files are held over the page, so the window says it can see what you are carrying. A drop holding nothing playable says so instead of doing nothing.

The drop is caught by Housekeeping rather than by the page, because a web page is never told where a dropped file lives and Bookbind needs the real path. Only files are registered for dragging, so text dragged into the title field behaves as it always did. Dragging in an ordinary web browser is not offered from this screen — the page says why, and **Choose folder…** is there instead.

## The run panel

**Make the audiobook** now opens a panel and keeps it for the life of that one run:

1. **Reading the files**, while it probes lengths and lays out the chapter list.
2. **Binding the audio**, with a real percentage and the amount of audio done out of the total.
3. **Checking the result**, as it compares the new file against what it asked for.
4. **Moving the originals aside** into `_originals`.
5. **Saved**, with the exact path the book was written to and **Show in Finder**.

**Stop** cancels the run and leaves the originals alone. **Keep running in the background** closes the panel without stopping anything, and **Progress** on the job in the list brings it back. **Try again** appears only after a failure or a stop. Escape does the same as closing.

The bundled Bookbind engine is 1.5.0, the same version as the standalone app.

## Downloads

- **Housekeeping-macOS-universal.zip:** Apple silicon and Intel in one app.
- **Housekeeping-macOS-arm64.zip:** Apple-silicon Macs only.
- **Housekeeping-macOS-x86_64.zip:** Intel Macs only.
- **SHA256SUMS.txt:** checksums for all three ZIPs.

Requires macOS 13 or later. The Bookbind screen needs Python 3 with `mutagen` (`python3 -m pip install mutagen`) and `ffmpeg` on the Mac, exactly as before.

The app is ad-hoc signed. Developer ID signing and notarization have not been completed.
