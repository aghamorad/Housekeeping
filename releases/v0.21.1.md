# Housekeeping 0.21.1

The Bookbind screen's **Search online catalogue** works again. That is the whole release.

## What was broken

Pressing it failed with

    CERTIFICATE_VERIFY_FAILED: unable to get local issuer certificate

which reads like a broken connection and is not one. A python.org Python on macOS
ships with **no root certificates** until its `Install Certificates.command` has been
run, and Python says nothing about that until the first https request: every TLS
connection then fails verification because there is nothing to verify against. The
catalogue search was the first thing on this Mac to make one.

## What changed

The trust store is chosen rather than assumed — `certifi`'s bundle when it is
installed, macOS's own `/etc/ssl/cert.pem` when it is not — so the lookup works on any
Mac that has either, and keeps working on a Python that has been set up properly. The
cover download uses the same context. The failure message, if it ever comes back, now
says the catalogue could not be reached and that both fields can be filled by hand.

This is **Bookbind 1.5.1**, carried inside the app:
<https://github.com/aghamorad/bookbind/releases/tag/v1.5.1>

Verified on this Mac with the bundled copy: `Greg Grandin` / `Empire's Workshop` returns
the audiobook from the iTunes catalogue, cover included.

## Downloads

- **Housekeeping-macOS-universal.zip:** Apple silicon and Intel in one app.
- **Housekeeping-macOS-arm64.zip:** Apple-silicon Macs only.
- **Housekeeping-macOS-x86_64.zip:** Intel Macs only.
- **SHA256SUMS.txt:** checksums for all three ZIPs.

Requires macOS 13 or later. The Bookbind screen needs Python 3 with `mutagen`
(`python3 -m pip install mutagen`) and `ffmpeg` on the Mac.

The app is ad-hoc signed. Developer ID signing and notarization have not been completed.
