# Housekeeping 0.20.0

A Local Models screen, and the five buttons at the foot of the menu bar panel work again.

## Local Models

**Local Models** is in the sidebar under Maintenance, and in **Jobs ▸ Local Models…** (⇧⌘I).

It is one list of everything on this Mac that can hold a model in memory, read from five
places at once:

- **Ollama**, through its own service — what is installed, what is loaded, and how much
  memory the loaded ones are holding.
- **LM Studio**, read as a folder rather than by waking the app, with its REST surface
  asked what is loaded only while it is already running.
- **The housekeeper**, this app's own weights and the llama-server that runs them.
- **Hermes (MLX)**, if that local server is up.
- **The Hugging Face cache**, listed as downloads rather than as models, because a file
  nothing can run is not something this screen can load.

Every row says what it weighs, and every row that can act has one button: **Load** while
it is on disk, **Unload** while it is in memory. Nothing is downloaded here, nothing is
deleted, and nothing loads by itself.

**Loading is measured before it is offered.** A model that needs more memory than is free
is shown with the arithmetic — "this one needs about 6.4 GB and 3.9 GB is free" — and no
button, because on a 16 GB Mac a model that does not fit does not fail politely. One
model loads at a time, and **Unload Everything** takes the lot out when the machine needs
the room back.

## The panel's five buttons

Open, Scan, Ask, MediaDock and Bookbind in the menu bar panel did nothing when clicked.

They were asking for a window by the wrong question: a window SwiftUI has finished with
stays in the app's window list with its style mask intact, so it still answers "can I
become the main window" — and ordering that one forward put nothing on screen. The live
window was always there, one entry further down the list.

Now the window that is actually up is the one raised; a minimized window is restored
instead of being left in the Dock; and an app refused activation still puts its window in
front. The panel is also reachable without a mouse — **Jobs ▸ Menu Bar Panel** (⇧⌘M) —
so a menu bar short of room cannot hide the only door to it.

## Downloads

- **Housekeeping-macOS-universal.zip:** Apple silicon and Intel in one app.
- **Housekeeping-macOS-arm64.zip:** Apple-silicon Macs only.
- **Housekeeping-macOS-x86_64.zip:** Intel Macs only.
- **SHA256SUMS.txt:** checksums for all three ZIPs.

Requires macOS 13 or later. The Bookbind screen needs Python 3 with `mutagen`
(`python3 -m pip install mutagen`) and `ffmpeg` on the Mac.

The app is ad-hoc signed. Developer ID signing and notarization have not been completed.
