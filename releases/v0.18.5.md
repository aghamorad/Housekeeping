# Housekeeping 0.18.5

This release brings the changes since 0.16.0 into one universal macOS build: clearer storage browsing, persistent tool navigation, a refined burgundy interface, a repaired Platinum skin, and an optional Housekeeper chatbot with a choice of local models.

## Storage and cleanup

- Search Clean Up results and sort by largest, smallest, name, or date. Categories show results as scanning progresses, with current-path feedback and cancellation.
- Inspect candidates, reveal them in Finder, and select the visible results while seeing how many selections are outside the current view.
- Expand app-related files without truncation. Uninstall confirmations list exact paths, and related data must be explicitly included.
- Filter the disk browser and choose from five sort orders. Main scan findings open largest-first.
- Keep disk, comparison, route, and phone state while moving between tools. Update and Terminal Health readings remain available when navigating away.
- Tighten app-data matching, filter protected apps and related data, and count duplicate or nested candidates once. Cleanup remains subject to the recorded safety policy and confirmation.

## Two finished appearances

The modern appearance retains burgundy, with soft directional lighting, satin controls, fine panel edges, quieter typography, and subtle hover feedback. The overview shows measured volume capacity and available storage, with direct access to cleanup, disk browsing, updates, and utilities.

Platinum now uses the same overview, with a wrapping toolbar that keeps every tool visible, a legible striped title bar, compact system type, square gray panels, and beveled buttons with press feedback. Its Settings button uses the native macOS Settings link. Modern lighting stays out of Platinum windows.

## Optional local chat

Chat starts **Off** unless a model choice has already been saved. Choosing a downloadable model never starts a download; the separate Download button shows its size first. Housekeeping's other tools remain available without chat.

An **Apple Intelligence** option uses Apple's on-device Foundation Model on eligible Macs running macOS 26 or later, with Apple Intelligence enabled and the system model ready. It needs no separate Housekeeping model download and has no cloud fallback. Other Macs can use the downloadable models.

Settings displays each downloaded model and its disk usage. Delete one model or all Housekeeping-managed downloads after reviewing the confirmation. Existing older weights are counted and remain until explicitly removed. Housekeeping does not delete Apple's system-managed model.

## Answers about the folder in front of you

Folder questions now prioritize the named or selected path over generic scan status. The discussed path stays visible, and follow-up questions retain that subject. Known locations and held scan results supply context; exact paths can receive a bounded, read-only check of directory metadata and up to 16 immediate child names. File contents are not read for this lookup. Missing or ambiguous paths remain explicit.

Conversation history uses the correct message roles, repeated long responses receive one retry, and generation can be stopped. The downloaded-model runtime releases memory after the panel has been closed for 45 seconds. General questions are supported too.

Generated answers remain fallible. Housekeeping's recorded cleanup assessment is displayed separately, and the chatbot cannot select items, move files, or change the cleanup policy.

## Downloads and compatibility

- **Housekeeping-macOS-universal.zip:** Apple silicon and Intel in one app. Choose this if unsure.
- **Housekeeping-macOS-arm64.zip:** smaller download for Apple-silicon Macs.
- **Housekeeping-macOS-x86_64.zip:** smaller download for Intel Macs.
- **SHA256SUMS.txt:** checksums for all three ZIPs.

The app requires macOS 13 or later. Apple Intelligence chat has the additional requirements described above. Model weights are optional downloads and are not included in these ZIPs. Bookbind's program files are bundled; its Python and media-tool dependencies still need to be available on the Mac.

The packages are ad-hoc signed and are **not Developer ID signed or notarized**. macOS may block the first launch. Source is available for inspection and local builds.
